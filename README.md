# GlassTune

유튜브 뮤직 미니 플레이어. 애플 리퀴드 글래스 스타일에, 창 크기에 따라 알약부터 풀 앨범아트까지 변신합니다.

Liquid Glass mini player for YouTube Music. Always-on-top, resizes from a pill to full album art.

## 특징

- **항상 위에** — 크롬 Document Picture-in-Picture 창이라 다른 앱 위에 떠 있습니다.
- **크기에 반응** — 창을 늘리고 줄이면 레이아웃이 4단계로 바뀝니다.
  | 높이 | 모습 |
  |---|---|
  | ~110px | 아트 + 제목. 마우스를 올리면 그 자리에 컨트롤이 떠오릅니다. |
  | ~200px | 아트 왼쪽, 제목 오른쪽, 아래에 컨트롤과 진행바 |
  | 200px~ | 아트가 위로 올라가고 가운데 정렬 |
  | 더 크게 | 아트가 가로를 꽉 채웁니다 |
- **유리** — 앨범아트를 블러로 깔고 그 위에 반투명 카드. 곡이 바뀌면 유리 색도 바뀝니다.
- **쫀득함** — 버튼, 진행바, 카드 등장 전부 스프링 커브.
- **컨트롤** — 좋아요, 이전, 재생/일시정지, 다음, 탐색, 유튜브 뮤직 탭으로 가기.

## 설치

크롬 116 이상이 필요합니다.

### 확장 프로그램

1. 이 저장소를 받습니다.
2. `chrome://extensions` → 개발자 모드 켜기 → **압축해제된 확장 프로그램을 로드합니다** → 받은 폴더 선택.
3. 유튜브 뮤직 탭에서 툴바 아이콘을 누르거나 `Alt+P`.

### 북마클릿

확장을 설치하고 싶지 않다면 `bookmarklet.html`을 열고 **🎧 YTM PiP** 버튼을 북마크바로 드래그하세요. 유튜브 뮤직 탭에서 북마크를 누르면 창이 뜹니다. 페이지를 새로 열 때마다 한 번씩 눌러야 합니다.

## 개발

디자인은 `pip.css`와 `pip.html`에, 로직은 `pip.js`에 있습니다. `pip.html`을 브라우저로 열면 그대로 미리보기가 되고, `preview.html`은 4가지 창 크기를 나란히 보여줍니다.

고친 뒤에는 빌드해야 실제 창에 반영됩니다.

```
node build.js
```

`pip.css`와 `pip.html`을 `pip.js`에 인라인해서 `pip.bundle.js`(확장용)와 `bookmarklet.html`(북마클릿용)을 만듭니다. 두 파일은 산출물이라 직접 고치지 않습니다.

| 파일 | 역할 |
|---|---|
| `pip.css` | 스타일, 크기별 레이아웃 |
| `pip.html` | 마크업. 미리보기 겸 PiP 창 템플릿 |
| `pip.js` | PiP 창 열기, 유튜브 뮤직과 연결 |
| `build.js` | 번들 생성 |
| `manifest.json`, `sw.js` | 크롬 확장 껍데기 |
| `preview.html` | 크기별 미리보기 |

## 동작 원리

유튜브 뮤직 탭 안에서 스크립트가 돌면서 `documentPictureInPicture.requestWindow()`로 창을 열고 그 안에 템플릿을 넣습니다. 곡 정보와 앨범아트는 `navigator.mediaSession.metadata`에서, 재생과 탐색은 페이지의 `video` 엘리먼트로, 이전·다음·좋아요는 유튜브 뮤직 플레이어바의 버튼을 대신 눌러 처리합니다. 유튜브 뮤직이 Trusted Types를 강제하므로 정책을 하나 만들어 `innerHTML`을 통과시킵니다.

## 한계

- 크롬은 창 자체 투명을 지원하지 않아서 유리 뒤는 앨범아트 블러입니다.
- 유튜브 뮤직 DOM이 바뀌면 이전·다음·좋아요 셀렉터가 깨질 수 있습니다. `pip.js` 상단에 모여 있습니다.
- 오디오 비주얼라이저는 스트림이 CORS를 열지 않아 불가능합니다.
